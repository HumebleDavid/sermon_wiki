# 홍동우 목사의 설교 저장소 (Theological & Sermon Web Archive)

홍동우 목사의 지난 10년(2016~2026)간의 설교문, 강의안, 외부 기고문 및 신학 위키 분석 지식베이스를 집대성한 독립형(Standalone) 정적 웹 애플리케이션입니다.

---

## 1. 아키텍처 및 특징

- **총 407편 문서 번들링:**
  - **📖 RAW 원본 아카이브 (138편):** 4대 사역 시기 설교문 126편 + 외부 기고문 12편
  - **🧠 WIKI 신학 지식베이스 (269편):** 시대별 총괄 보고서 5편 + 연속 강해 거시 분석 16편 + 핵심 신학 개념 66편 + 신학자 및 사상가 42편 + 개별 1:1 분석 노트 138편 + 마스터 카탈로그 및 로그 2편
- **좌측 2단 수직 분할 사이드바 (50% / 50%):**
  - 상단 50%: `📖 RAW 원본 아카이브` (4대 사역 시기 및 기고문 아코디언 트리)
  - 하단 50%: `🧠 WIKI 신학 지식베이스` (총괄보고서, 연속강해, 개념, 신학자, 개별 분석노트 트리)
  - 상/하단 독립 스크롤 적용.
- **실시간 통합 검색 (Full-text & Metadata Search):**
  - 제목, 성경 본문(`scripture`), 태그(`tags`), 핵심 주제(`subject`), 본문 키워드 실시간 색인 검색 및 하이라이트.
- **스마트 교차 네비게이션:**
  - RAW 설교문 열람 시 상단에 `[🧠 WIKI 분석 노트 보기]` 버튼 노출
  - WIKI 분석 노트 열람 시 상단에 `[📖 RAW 원본 설교문 보기]` 버튼 노출
- **학술적 타이포그래피 & 독서 최적화:**
  - 서체 선택: 품격 있는 신학 명조체(`Noto Serif KR`) ↔ 깔끔한 고딕체(`Noto Sans KR`)
  - 글자 크기 5단계 스테퍼: 15px ~ 22px (기본 18px)
  - 듀얼 테마: 따뜻한 한지(Parchment) 미색 라이트 모드 ↔ 깊은 슬레이트 다크 모드 (사용자 설정 `localStorage` 자동 보존)
  - 줄간격 1.85, 최대 읽기 폭 840px로 장문 독서 피로도 최소화.
- **옵시디언 고유 문법 완벽 렌더링:**
  - YAML 프론트매터 메타데이터 요약 카드
  - `[[문서명]]` 위키링크 SPA 무지연 라우팅
  - `> [!quote]`, `> [!abstract]`, `> [!question]` 등 콜아웃 카드
  - 3단 인용구 블록(Verbatim 발췌 + 강해 및 목회적 맥락 + 신학적 함의) 최적화 시각화.
- **완벽한 반응형 모바일 지원:**
  - 화면 폭 860px 이하에서 햄버거 메뉴(`☰`) 기반 좌측 슬라이딩 드로어 메뉴 제공.

## 2. 실행 방법

본 웹사이트는 별도의 백엔드 데이터베이스나 복잡한 빌드 도구 없이 브라우저에서 즉시 작동합니다.

### 방법 A: 로컬 HTTP 서버 실행 (권장)

터미널에서 아래 명령어를 실행한 후 브라우저로 접속합니다:

```bash
cd /Users/hongdong-u/Documents/LLM_Wiki
python3 -m http.server 8000
```
브라우저 주소창: `http://localhost:8000/03_Web/`

### 방법 B: 브라우저로 직접 열기 (Double Click)

`03_Web/index.html` 파일을 더블 클릭하거나 브라우저(크롬, 사파리, 엣지 등)로 드래그하여 바로 열 수 있습니다. (CORS 제약이 없는 `data.js` 번들 구조이므로 `file://` 프로토콜에서도 완벽히 동작합니다.)
